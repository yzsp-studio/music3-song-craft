# 歌词结构优化

## 1. 总原则

用户提供歌词时：**保留韵脚、句数、段落划分与词意**，只做结构层优化（加段落标签、调顺序、补副歌重复、规范拼写与格式）。不得擅自改写歌词内容；确需微调必须征得用户同意。用户未提供歌词时，可代写，但代写前必须弹窗确认：语言、主题、目标时长、人声性别与音色倾向。

## 2. 段落标签规范

- 只允许官方 14 种标签（见 references/official-rules.md §3）。
- 每个歌词段上方加一行 `[标签]`；同段内不再重复标签。
- 变体写法：[Verse 1] [Verse 2] [Final Chorus] [All in Chorus] [Breakdown to drums-Chorus]。
- 拼写规范化对照：

| 用户常见写法 | 规范为 |
|---|---|
| [Prechorus] / [Pre-Chorus] / [预副歌] | [Pre-chorus] |
| [副歌] / [高潮] | [Chorus] |
| [主歌1] / [A段] | [Verse 1] |
| [桥段] / [过门] | [Bridge] |
| [前奏] | [Intro] |
| [间奏] | [Interlude] |
| [尾奏] / [结尾] | [Outro] |
| 其它自造标签 | FAIL_TAG_NOT_OFFICIAL |

## 3. 默认结构模板（按目标时长裁剪）

```
[Intro]                    ← 8–20 秒器乐，可留空由模型生成
[Verse 1]
[Pre-chorus]
[Chorus]
[Interlude] 或 [Instrumental]   ← 8–20 秒
[Verse 2]
[Pre-chorus]
[Chorus]
[Bridge]
[Final Chorus] 或 [Chorus]
[Outro]                    ← 8–25 秒，可留空由模型生成
```

裁剪规则：
- 目标时长 < 3:30：删 [Bridge] 或删第二个 [Pre-chorus]，保留副歌 2 次。
- 目标时长 3:30–4:30（默认推荐）：完整模板。
- 接近 5 分钟上限：先删重复段落，再压缩长句，保留 Intro / Chorus / Outro 骨架。
- 电子曲风可用 [Build-up] → [Drop] 替换部分 [Pre-chorus] → [Chorus]。

## 4. 副歌与 Hook 规则

- 副歌必须至少出现 2 次；第 2 次起可用 [Final Chorus] 收尾（缺复现 → FAIL_STRUCTURE_NO_CHORUS_REPEAT）。
- Hook 句（全曲最洗脑的一句）控制在 5–10 字，放在副歌开头或结尾，并在每次副歌中逐字重复。
- 副歌重复时词可以微变（如"我愿"→"我会"），但骨架句保持一致。

## 5. 非语言人声占位

- 需要哼唱 / 吟唱时，在对应段落内写发音音节：`"ooh, ooh, ooh..."`、`"la, la, la..."`、`"mmm, mmm..."`、`"ah, ah, ah..."`。
- 音节行同样置于所属段落标签之下。

## 6. 字符数计算（必须精确）

- 每个汉字 = 2 字符；每个标点符号、空格、英文字母 = 1 字符。
- 歌词字符总数 = 汉字数 × 2 + 其他字符数；上限 3500，超限 → FAIL_LYRICS_CHAR_OVERFLOW。
- 段落标签行与音节行计入总字符。

## 7. 时长估算（写进校验报告）

公式：预计时长 ≈ 人声时长 + 器乐段时长

- 人声时长按节奏密度估算（按汉字计）：
  - 抒情慢歌（60–80 BPM）：每 100 字约 60–80 秒
  - 中速流行（90–110 BPM）：每 100 字约 45–60 秒
  - 快歌 / 说唱（≥120 BPM）：每 100 字约 30–45 秒
- 英文歌词按音节估算：约 2.5–4 音节 / 秒。
- 器乐段：[Intro] 8–20 秒、[Interlude] 8–20 秒、[Outro] 8–25 秒、[Solo] / [Instrumental] 10–30 秒，逐段相加。
- 预计时长 > 300 秒（5 分钟）→ FAIL_DURATION_OVER_5MIN，必须给出删减方案。
- 建议安全区间：3:30–4:30，为模型编排留余量。

## 8. 输出格式

优化后的歌词以单个代码块输出（用户可直接整段复制）：

```
[Intro]
[Verse 1]
...
[Chorus]
...
[Outro]
```

标签行与歌词行之间不空行；段与段之间空一行。中英文混搭时中文歌词保持中文，不逐句翻译。
