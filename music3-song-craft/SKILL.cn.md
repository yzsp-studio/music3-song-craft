# 曲匠工坊

## 核心原则

把目标定义为「可直接送进 Music 3.0 的生成材料」：歌词带官方标签、字符数合规、提示词五要素齐全、时长不超限、校验全 PASS。不承诺音色复刻、不承诺超 5 分钟、不承诺商用授权。

## 最高优先级规则索引

1. 官方规则锁：14 种段落标签、3500/2000 字符上限、5 分钟上限、非语言音节占位、无音色复刻。
2. 三件套输出：优化歌词 + 中英双语风格提示词 + 校验报告。
3. 五要素：曲风、速度/拍号/调性、情绪弧线、人声特质、配器与混音。
4. 尊重原词：只做结构层优化，不擅自改写歌词内容。
5. 副歌复现：至少 2 次，第二次可用 [Final Chorus]。
6. FAIL 路由：FAIL_* 必须回退修复，最多 2 次，失败如实上报。

## 快速路由

0. 给了歌词草稿 → 结构优化入口。
1. 只给主题 → 弹窗确认语言/主题/时长/人声 → 代写歌词 → 结构优化。
2. 只给曲风 → 风格提示词入口，提醒歌词与风格不可同时为空。
3. 校验已有内容 → 只跑校验清单。
4. 要模板 → 输出风格模板库。
5. 改上一版 → 增量修改并重新校验。

## 标准流程

步骤 1 输入验证：歌词与风格至少一项；缺项要求补充；代写歌词前强制弹窗确认。
步骤 2 规则读取：按入口读取对应 reference 文件并记录。
步骤 3 优化与自检：产出草稿 → 对照校验清单逐条 PASS/FAIL → FAIL 回退修复（最多 2 次）。
步骤 4 输出：三件套（歌词代码块 + 中英双语提示词代码块 + 校验报告）。

## 关键参数速记

- 14 标签：Intro、Verse、Pre-chorus、Chorus、Hook、Drop、Bridge、Solo、Build-up、Instrumental、Breakdown、Break、Interlude、Outro。
- 歌词 ≤3500 字符（汉字 = 2 字符）；风格 ≤2000 字符；单曲 ≤5 分钟；默认建议 3:30–4:30。
- 哼唱占位："ooh, ooh..."、"la, la..."、"mmm..."、"ah..."。
- 输出 32kHz 16bit 立体声，产品端导出 mp3。
