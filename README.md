## 🇬🇧 English

This skill turns lyric drafts, creative intent, or genre requirements into a three-piece kit you can paste straight into Music 3.0: optimized lyrics carrying official section tags, a bilingual structured style caption, and a validation report. It covers checking official rules, restructuring lyrics, writing the five elements of a Structured Caption, a style template library, duration and character-count estimation, and FAIL_* self-check rework. A top-priority rule index runs the whole chain to prevent incomplete execution and rule regression, and the standard flow is a mandatory four steps that start with an input gate—thin material is blocked before any writing begins—then required rule reads.

### ✨ What it does

- Lyric draft in, official section-tagged lyrics out, ready to paste
- Produces a bilingual Structured Caption with all five elements covered
- Ships with a validation report: official-rule check plus FAIL_* rework passes
- Estimates song duration and lyric character counts so nothing gets rejected for overflow
- Built-in style template library per genre, so you never describe a style from scratch
- Mandatory four-step flow plus a top-priority rule index prevents skipped steps and rule regression
